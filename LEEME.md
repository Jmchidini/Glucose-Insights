# Glucose Insights APK

Carpeta central del proyecto de conversión a Android.

Para actualizar el código en Jmchidini/Glucose-Insights: abrir ACTUALIZAR_GITHUB.bat.
Para revisar la selección sin conexión: REVISAR_SIN_SUBIR.bat. Consultar GITHUB.md.

- Codigo: versión adaptada, pruebas e instrucciones. Para ejecutarla en Windows, abrir iniciar_app.bat con Python instalado.
- Datos de ejemplo: TSV Stream y CSV LibreView aportados por el usuario; contienen datos personales de glucosa.
- Originales: ZIP del proyecto original.
- Distribuciones: ZIP de la versión adaptada.
- Informes de prueba: PDF generado con los últimos 15 días del TSV Stream.

Estado: primera APK de prueba compilada para Android 9 (API 28), ARM de 32 bits.
El proyecto Android y las instrucciones de instalación están en Android/.
La APK está en Distribuciones/Glucose-Insights-0.1-Android9.apk.
Carga de ambos formatos y generación de PDF verificadas en computadora con
Python 3.10 y las versiones principales elegidas para Android. Falta probar
instalación, generación y rendimiento en el Galaxy J7 Neo.

Se conservaron los archivos en sus ubicaciones originales. No se incluyeron cachés, bibliotecas descargadas ni imágenes temporales de revisión.
